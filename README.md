# 강아지·고양이 닷지 🐶🐱

방향 이동으로 장애물을 피하며 생존 시간을 겨루는 2D 회피(닷지) 게임입니다.
바닐라 JS + Canvas 2D, 빌드 도구 없는 순수 정적 사이트로 구성되어 있습니다.

## 플레이 방법

- **PC**: 방향키(↑↓←→)로 8방향 이동, 스페이스바로 일시정지
- **모바일**: 화면 아무 곳이나 터치하면 그 지점이 조이스틱 중심이 되고, 드래그 방향으로 이동
  - 손가락이 중심에서 `JOYSTICK.MAX_RADIUS`(48px)보다 멀어지면 중심이 손가락을 따라 끌려온다.
    방향을 반대로 꺾는 데 필요한 손가락 이동거리를 상한선으로 묶어 조작 반응을 일정하게 유지하기 위한 것
- 위·옆·대각선에서 날아오는 장애물을 피해 최대한 오래 생존하세요
- 하트 아이템을 먹으면 HP가 회복됩니다 (최대 3)

## 로컬 실행

ES 모듈을 사용하므로 간단한 로컬 서버가 필요합니다 (`file://` 직접 열기 불가):

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 기술 개요

- 논리 좌표계 720×1280 (9:16) 기준으로 모든 게임 로직이 동작 — 기기 크기와 무관하게 공평한 기록 경쟁
- `requestAnimationFrame` + deltaTime 기반 게임 루프 — 프레임 드랍 시에도 게임 속도 동일
- 밸런스 상수는 전부 `js/constants.js` 한 곳에서 튜닝
- 최고 기록·마지막 선택 캐릭터는 `localStorage`에 저장

## 파일 구조

```
index.html          — 단일 페이지 (화면 오버레이 포함)
css/style.css       — 스타일 (BEM)
js/
  constants.js      — 밸런스·규격 상수
  storage.js        — localStorage 안전 래퍼
  viewport.js       — 논리 좌표 스케일링·세이프에어리어
  input.js          — 키보드 + 플로팅 조이스틱
  characters.js     — 캐릭터 정의·렌더러 (이미지 교체 진입점)
  entities.js       — 장애물·아이템 스폰/이동/충돌
  ui.js             — DOM 오버레이 화면 관리
  main.js           — 상태 머신·게임 루프·HUD
```
